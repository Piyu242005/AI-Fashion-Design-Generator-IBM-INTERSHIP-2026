⚠️ One Thing You Must Do First

You need a free Google Gemini API key to use AI features (quiz, chat, summary, flashcards).
Get it in 30 seconds: Go to aistudio.google.com → Sign In → "Get API Key" → Create → Copy.
Open the file study-buddy/.env in Notepad and change:
GOOGLE_API_KEY=your-google-gemini-api-key-here
to your actual key: GOOGLE_API_KEY=AIzaSy...your-real-key...
Without the API key, the app still runs — you can register, login, upload documents, and browse the UI. Only the AI features (chat, quiz, summary, flashcards) will return an error.
