# Code of Conduct

## Our Commitment

We are committed to providing a welcoming, respectful, and professional environment for everyone participating in this project.

This project is an educational and internship project, and constructive collaboration is encouraged.

---

## Expected Behavior

All contributors, maintainers, and participants are expected to:

- Be respectful and professional.
- Communicate clearly and constructively.
- Provide useful and respectful feedback.
- Respect different opinions and approaches.
- Focus on improving the project.
- Give appropriate credit to original work.
- Follow the licenses of third-party software, models, APIs, and datasets.
- Respect the privacy of other users and contributors.
- Report security issues responsibly.
- Follow GitHub's Terms of Service and Community Guidelines.

---

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Threats or intimidation.
- Hate speech.
- Sexual harassment.
- Trolling or deliberately disruptive behavior.
- Publishing someone's private information without permission.
- Sharing passwords, API keys, tokens, or other sensitive information.
- Malicious code submissions.
- Deliberate attempts to damage the project or its infrastructure.
- Misrepresenting someone else's work as your own.
- Abusing third-party APIs or services.
- Circumventing security controls or usage restrictions.

---

## Contribution Guidelines

Contributors should:

1. Read the project documentation before making changes.
2. Create focused and meaningful commits.
3. Avoid unnecessary changes to unrelated parts of the project.
4. Test changes before submitting a Pull Request.
5. Explain significant changes clearly.
6. Respect existing project architecture.
7. Avoid committing secrets or credentials.
8. Respect third-party licenses.
9. Keep Pull Requests focused and reviewable.

---

## AI-Generated Contributions

AI-assisted development tools may be used in this project.

However, contributors remain responsible for:

- Reviewing generated code.
- Testing generated code.
- Checking security implications.
- Verifying dependencies and licenses.
- Ensuring that generated content does not violate third-party rights.
- Understanding the code they submit.

AI-generated code should not be submitted blindly without review.
