Upgrade 1 — AI Agent Architecture

Instead of a single monolithic RAG call, the system uses an Intent-Routing Agent that classifies the user's request and dispatches it to a specialised sub-agent. This follows modern agentic AI design patterns and significantly elevates the project.

Agent Routing Logic

Upgrade 2 — AI Recommendation Engine

The recommendation engine analyses quiz scores stored in SQLite, identifies topics where scores are below 70%, and prompts Gemini to generate a personalised revision plan with targeted practice questions.

Data Flow

  • Input: Quiz scores by topic (SQLite quiz_results table)
  • Processing: Weighted average per topic; topics <70% flagged as "weak"
  • AI Call: Gemini generates a revision priority list and 5 practice questions per weak topic
  • Output: Dashboard card "Today's Recommendations" + auto-generated practice quiz
  • Loop: Scores update after each quiz → recommendations refresh dynamically
