#  IMPORTANT — NumPy policy:
#    Do NOT pin numpy here.  Colab ships numpy 2.x; scipy was compiled
#    against that ABI.  Pinning numpy==1.26.4 downgrades numpy and breaks
#    scipy's compiled C extensions, which cascades through:
#      transformers → loss_for_object_detection → scipy.optimize
#      → numpy._core._multiarray_umath._blas_supports_fpe  (absent in 1.26)
#      → CLIPImageProcessor fails → StableDiffusionXLPipeline fails.
#    Use whatever numpy Colab ships.  Tested with 2.0.2.
#
#  IMPORTANT — Pillow policy:
#    Do NOT cap Pillow at <11.  Colab ships Pillow 11.x which works fine
#    with all Stage 1 operations.
#

#    - auto1111sdk         (removed; Python 3.10-only, broken CLIP dep)
#    - clip                (OpenAI CLIP pip package conflicts with Colab)

#    - torchsde            (not used by current generate_model.py)
#    - k_diffusion         (not used by current generate_model.py)
